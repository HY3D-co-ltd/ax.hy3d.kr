회사 자료를 열고, 업무에 맞는 봇에게 요청하세요

워크숍을 맡은 운영팀은 프로젝트 폴더에 단가표, 참가 안내문, 운영 브리핑을 모아 둡니다. 견적을 낼 때는 견적서 봇을, 모집 글을 쓸 때는 마케팅 봇을 선택합니다. 같은 행사라도 각 봇에 건네는 자료와 기대하는 결과가 달라집니다.

견적서 자동화

견적 요청을 항목별 금액으로 풀어 보세요

“20명이 참여하는 워크숍입니다. 강의 2회와 교재 20부, 실습 재료 20세트로 견적을 잡아 주세요.” 견적서 봇에는 고객 요청과 회사 단가표를 함께 건넵니다. 담당자는 계산 근거를 확인하고 고객에게 보낼 범위를 결정합니다.

어디까지 견적에 포함할까요?

강의 2회는 70만 원, 교재 20부는 16만 원, 실습 재료 20세트는 24만 원입니다. 기본 견적은 세 항목을 합한 110만 원입니다. 추가 인쇄비는 수량과 단가를 확인한 뒤 별도로 견적을 냅니다.

요청서와 견적 CSV를 각각 탭으로 열면 “20부”가 표에 그대로 들어갔는지 확인하고 셀을 직접 수정할 수 있습니다.

작업지시서 자동화

견적서의 ‘교재 20부’를 제작팀이 실행할 지시로

견적이 확정되면 운영총괄에 수량과 행사 일정을 건네고 준비 작업을 나눠 달라고 요청하세요. 제작 담당이 언제까지 무엇을 준비해야 하는지, 운영 담당이 무엇을 확인해야 인계받을 수 있는지 한 문서에 정리합니다.

‘인쇄 완료’의 기준까지 전달합니다

제작 담당은 행사 3일 전까지 최종 PDF와 대조한 교재 20부를 준비합니다. 운영 담당은 행사 전날까지 수량표와 대조한 실습 키트 20세트를 인계합니다.

발주 전 확인할 일은 따로 남깁니다

기본 수량을 옮긴 뒤에도 예비 교재 수량, 추가 인쇄 단가, 납품 장소는 결정이 필요합니다. 문서 아래에 체크리스트로 남기면 다음 담당자가 확인을 이어갈 수 있습니다.

홈페이지 관리

참가자가 보는 페이지에서 신청과 문의까지 확인하세요

홈페이지 봇에 최신 모집 안내와 수정할 페이지를 건네세요. 이 워크숍에서는 정원 20명, 강의 2회, 준비물 두 가지를 안내합니다. 담당자는 수정안을 앱에서 열어 방문자가 프로그램을 이해하고 신청 방법을 찾을 수 있는지 살펴봅니다.

데스크톱과 모바일에서 ‘참가 신청 안내’와 ‘문의 방법’을 열어 도착 위치를 확인하세요. 담당자가 모집 내용과 화면 배치를 검토한 뒤 운영 사이트에 적용할 변경을 결정합니다.

마케팅 자동화

하나의 참가 안내문으로 블로그 글과 SNS 원고를 준비하세요

마케팅 봇에 참가 안내문과 게시할 채널을 알려주세요. 블로그 원고에는 첫 시간에 배울 내용과 실습 후 가져갈 결과물을 담습니다. SNS 원고는 팀에서 자주 겪는 문제를 첫 문장에 놓고, 강의 횟수와 모집 인원을 짧게 안내합니다.

채널에 맞춰 원고 검토하기

두 원고의 길이와 첫 문장은 달라도 정원과 프로그램은 같아야 합니다. 원본 참가 안내문과 대조한 뒤 신청 마감일과 링크를 확인합니다.

다음 초안 작성 예약하기

기본 예약의 제안 시간은 오전 9시입니다. 담당 봇과 요청 내용을 확인하고 팀 일정에 맞춰 재개하세요. 채널 게시와 광고 집행은 별도 승인을 거칩니다.

운영 브리핑

다음 날 아침, 끝난 일과 확인할 일을 이어 보세요

운영총괄의 아침 브리핑은 업무 기록과 산출물을 읽어 성공·실패·미확인 항목을 나누도록 설정돼 있습니다. 제작팀에 넘긴 교재 수량은 근거 문서와 대조하고, 답을 받지 못한 추가 인쇄 단가는 다음 담당자가 확인할 일로 남길 수 있습니다.

팀 근무 시간에 맞춰 재개하세요

기본 브리핑은 현지 시각 오전 9시로 설정돼 있고 처음에는 일시 중지되어 있습니다. 실행 위치와 계정을 준비한 뒤 재개하면 자동화 상세 화면에서 일정과 최근 실행을 확인할 수 있습니다.

공식 API와 사용량 한도

독립 Windows 앱

첫 Windows 버전은 이 페이지에서 직접 설치하는 방식으로 배포합니다. 초기 설치 파일에는 코드 서명이 없어 Windows가 실행 전 경고를 표시할 수 있습니다.

공식 Windows x64 다운로드는 준비 중입니다. 설치와 제거를 확인한 뒤 이곳에 링크를 게시합니다.

자주 묻는 질문

지금 설치하거나 결제할 수 있나요?

현재 Windows 공개 배포를 준비하고 있습니다. 공식 다운로드 링크가 게시되면 앱에서 Google 계정으로 시작할 수 있습니다.

회사 API 키가 앱에 들어가나요?

회사 API 키는 서버에 보관합니다. 앱에서는 고객 계정으로 로그인해 허용된 모델과 잔액을 사용합니다.

AX 워크스페이스와 같은 서비스인가요?

별도 제품입니다. AX Works는 Windows 업무 앱이며, AX 워크스페이스는 맞춤형 웹 업무 공간입니다.
