AX Works

견적 요청이 들어오면 회사 양식과 단가표로 견적서 초안을 만들고, 확정된 내용을 담당자별 작업지시서로 정리하세요. 홈페이지 공지와 마케팅 원고도 같은 프로젝트 자료로 준비할 수 있습니다.

도입 문의

Windows x64 설치 파일을 준비했습니다. 설치와 제거를 확인한 뒤 이곳에 공식 다운로드 링크를 게시합니다.

워크숍 문의 한 건에서 시작하는 네 가지 업무

견적서 자동화

“강의 2회, 교재 20부로 견적을 잡아 줘.” 견적서 봇이 회사 단가표에서 항목을 찾아 수량과 금액을 계산하고, 추가 인쇄비처럼 확인이 필요한 항목을 따로 표시합니다.

작업지시서 자동화

확정된 견적을 운영총괄에 건네면 강의 준비, 교재 인쇄, 실습 재료 포장을 작업지시서 초안으로 정리합니다. 작업마다 담당자·기한·완료 기준을 적고, 아직 정해지지 않은 내용은 확인할 항목으로 남깁니다.

홈페이지 관리

홈페이지 봇이 모집 일정과 참가 안내를 바탕으로 신청 페이지 수정안을 준비합니다. 휴대폰에서도 신청 버튼과 문의 경로를 찾을 수 있는지 확인하고, 운영 사이트에는 승인된 변경을 반영합니다.

마케팅 자동화

마케팅 봇이 같은 참가 안내문을 블로그용 모집 글과 SNS용 짧은 글로 다듬습니다. 초안 작성을 예약하고, 담당자가 원고와 채널을 확인한 뒤 게시나 광고 집행을 승인합니다.

견적 근거를 원본 표에서 확인하세요

강의 2회에 회당 35만 원이면 강의비는 70만 원입니다. 담당자는 봇에 전달한 수량과 단가를 CSV에서 직접 대조하고, 견적이 확정되면 같은 수량으로 교재 인쇄와 재료 포장을 지시할 수 있습니다.

업무 환경과 배포 안내

업무별 프로젝트

문서와 작업 맥락을 정리하고 AI와 다음 할 일을 검토합니다. 결과는 사용자가 확인합니다.

공식 API와 사용량 한도

Claude와 GPT가 하나의 AX 크레딧 잔액을 사용합니다. 요청에 필요한 크레딧이 부족하면 회사 API 호출을 멈춥니다.

독립 Windows 앱

첫 Windows 버전은 이 페이지에서 직접 설치하는 방식으로 배포합니다. 초기 설치 파일에는 코드 서명이 없어 Windows가 실행 전 경고를 표시할 수 있습니다.

자주 묻는 질문

지금 설치하거나 결제할 수 있나요?

현재 Windows 공개 배포를 준비하고 있습니다. 공식 다운로드 링크가 게시되면 앱에서 Google 계정으로 시작할 수 있습니다.

회사 API 키가 앱에 들어가나요?

회사 API 키는 서버에 보관합니다. 앱에서는 고객 계정으로 로그인해 허용된 모델과 잔액을 사용합니다.

AX 워크스페이스와 같은 서비스인가요?

별도 제품입니다. AX Works는 Windows 업무 앱이며, AX 워크스페이스는 맞춤형 웹 업무 공간입니다.
