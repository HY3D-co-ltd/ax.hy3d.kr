문서와 작업 맥락을 정리하고 AI와 다음 할 일을 검토합니다. 결과는 사용자가 확인합니다.

공식 API와 사용량 한도

계정별 사용량과 비용 상한을 확인하는 구조를 개발하고 있습니다. 무제한 AI 이용을 제공하는 상품은 아닙니다.

독립 Windows 앱

AX 전용 설치·업데이트 경로를 준비합니다. 설치 파일과 자동 업데이트는 아직 제공하지 않습니다.

요금제는 준비 중입니다

Free, Pro 월 30,000원, Premium 월 300,000원과 Enterprise 사용량 기반 선불 충전을 계획하고 있습니다. 가격은 검토안이며, 부가세·포함 크레딧·지원 모델·추가 충전 단위와 상한은 출시 전에 확정합니다. 지금은 가입·카드 등록·결제를 받지 않습니다.

고객 본인의 공식 CLI 또는 API 연결 방식과 이용 조건은 공급자 정책 확인 후 안내합니다. 개인 AI 구독을 무제한 재판매하는 서비스가 아닙니다.

자주 묻는 질문

지금 설치하거나 결제할 수 있나요?

아직 아닙니다. 공개 설치 파일과 결제는 준비 중이며, 도입 문의만 받고 있습니다.

회사 API 키가 앱에 들어가나요?

회사 제공 API는 키를 앱에 넣지 않는 서버 프록시 방식으로 설계합니다. 실제 서비스 출시와 개인정보 처리 조건은 별도로 고지합니다.

AX 워크스페이스와 같은 서비스인가요?

별도 제품입니다. AX Works는 Windows 업무 앱이며, AX 워크스페이스는 맞춤형 웹 업무 공간입니다.
