복잡한 과제 일정, 작업 단위로 정리하세요.

WBS와 간트 차트로 작업 구조, 일정 변경, 진행 상황을 확인하는 웹서비스입니다. 현재 허용된 회사 계정으로 이용할 수 있습니다.

과제 계획과 진행 상황을 한곳에서

WBS는 과제의 범위를 산출물과 세부 작업으로 나눈 표입니다. WBS Planner는 이 작업 구조와 간트 차트를 연결해 일정과 변경 사항을 함께 보도록 돕습니다.

산출물을 작업으로 나누기

과제에서 제출하거나 완료할 산출물을 먼저 정하고, 담당자가 실행할 세부 작업으로 나눕니다.

일정과 변경 사항 확인

간트 차트에서 작업이 진행되는 시점을 보고, 처음 계획과 달라진 부분을 확인합니다.

개발 작업과 검증 연결

개발 항목에 대응하는 테스트 작업을 연결해 어떤 결과를 검증해야 하는지 확인합니다.
