# 하이쓰리디 AI 소개 홈페이지

GitHub Pages가 main 브랜치를 ax.hy3d.kr에 배포합니다.

## AX Works Windows 다운로드

제품 페이지는 이 저장소의 최신 정식 릴리스에 있는 `ax-works-windows-setup.exe`와 `SHA256SUMS.txt`를 가리킵니다. 새 버전을 배포할 때 홈페이지 파일을 수정할 필요가 없습니다.

1. 버전별 새 태그로 초안 릴리스를 만들고 설치 파일과 같은 파일명의 SHA-256 체크섬을 함께 올립니다. 비공개 AX Works 저장소에서 가져왔으면 공개 사본과 원본의 바이트 및 해시가 일치하는지 확인합니다.
2. 두 파일을 검증한 뒤 릴리스를 게시하고 GitHub의 Latest로 지정합니다. 다른 제품의 릴리스는 이 저장소에서 Latest로 지정하지 않습니다.
3. 제품 페이지의 다운로드와 체크섬 링크를 로그인 없이 열어 새 파일의 해시와 대조합니다. 이 절차는 수동 설치용 다운로드를 갱신합니다.
